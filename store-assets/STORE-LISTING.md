# Chrome Web Store listing — Notely v2.1.1 (release candidate draft)

**Extension title:** Notely – Clean Notes

**Short description:** Capture ideas, organize notes, and write Markdown in Chrome. Private, local-first, with backup and restore.

## Detailed description (English)

Notely is a minimal, local-first notes workspace for Chrome.

- Capture selected text from webpages using the context menu.
- Write and preview Markdown in a compact popup, side panel, or full workspace.
- Organize notes with search, tags, favorites and pinned notes.
- Create a manual JSON backup and restore it when needed.
- Use local notes without creating a cloud account.
- Optionally support the project through a USDC-on-Solana address; no wallet connection or payment service is required.

Notes are stored in the Chrome profile using `chrome.storage.local`. This is not cloud synchronization. Back up valuable notes before uninstalling the extension or clearing browser data. Only send USDC on Solana to the shown donation address after independently verifying current deposit details.
