# Security Policy

## Scope

Notely is a Chrome Manifest V3 extension storing notes locally. Backups may contain sensitive user-authored content.

## Reporting

**Do not publish exploit details or private notes in a public issue.** Contact the repository owner using GitHub private contact/security reporting functionality when enabled. No dedicated security email or disclosure SLA is currently published.

## Sensitive data

Never share note exports, browser profile data, Chrome extension signing keys, API secrets or personal recovery information in issues, logs or pull requests. This repository does not require user credentials to run.

## Verification boundary

Automated tests and local static Chromium previews are not a full assessment of installed Chrome behavior. Security assurances should be independently verified before distribution.
